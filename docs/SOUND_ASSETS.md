# Click Sound Assets

The app bundles five shortened WAV derivatives prepared from source files
supplied by the repository owner.

| Bundled file | Source file | Edit |
|---|---|---|
| `mouse-click.wav` | `Mouse Click-1.wav` | Trailing silence removed and peak adjusted |
| `plop-click.wav` | `Plop Click.wav` | Trailing silence removed and peak adjusted |
| `typewriter.wav` | `Typewriter Press Single Button.wav` | Trailing silence removed and peak adjusted |
| `spacebar.wav` | `Computer Keyboard Press Space Bar.wav` | Trailing silence removed and peak adjusted |
| `mouse-pop.wav` | `mouse pop.wav` | Leading and trailing silence removed and peak adjusted |

All bundled files are 44.1 kHz, stereo, 16-bit PCM WAV files. The edits keep
each effect short enough for repeated clicking without a long silent tail.

Before public distribution, store the commercial license receipt or terms for
each source file with the release records. The source license documents are not
currently part of this repository.
